# RC3.3 — approved flexible collections and supplemental renewals

Approved 26 November 2026. RC3.2 remains the immutable accepted visual baseline and working preview. One parish cycle per service year; independent original ministry submissions from online or walk-in channels; optional supplemental batches reference the original; prior submitted names and recommendation coverage are read from the same cycle. No simultaneous submission requirement, no duplicate assignment or charge. Staff independently review each recommended assignment, then explicitly group one or more compatible reviewed batches for a single exact settlement via existing RC3 ledger. No partial payment within an obligation; Curia accountability unchanged. Prior settled batches are not reopened. Existing no-renewal decisions may be included in supplemental intake; rejected proposals require controlled reconsideration (not yet implemented). Unallocated collections without names remain an exception design item; do not enable them by bypassing approved obligations.
