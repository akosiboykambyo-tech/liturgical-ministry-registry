# RC2 demonstration — brand alignment

Reference: COWL-DOK Digital Brand & UI Style Guide v1.0 (19 November 2026), pp. 3–10; working reference pending formal diocesan approval.

- Reuse canonical registry CSS palette; action red for primary actions, oxblood navigation, teal text links, ink and muted plum copy.
- Retain EB Garamond and Inter, Phosphor Light, existing institutional SVG without cropping or recoloring. Compact rail uses a textual COWL-DOK label, not a new logo. Remove the placeholder façade from demo login.
- Proposed staff-workspace extensions: 1350px max container to accommodate tables; 24/32px gutters, 3px panel corners, 44px main controls, darker form borders, quiet semantic success/error surfaces. These are scoped to the demo; no changes to public/admin global design tokens or financial authorization.
- Keep TEST environment guard, fictional notice and watermarks. No official print activation.
- Build/regression checks do not establish WCAG compliance or authenticated browser acceptance. Verify responsive navigation, forms, print draft and keyboard states with actual TEST accounts before presentation.
